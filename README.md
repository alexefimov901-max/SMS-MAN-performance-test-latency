# SMS-MAN performance test

## 1. Intro — SMS-MAN performance test

**SMS-MAN performance test** focuses on how virtual number services perform in real conditions: latency, delivery success, and uptime.

Many platforms require SMS verification, and using a personal number is often not practical. The typical use cases—privacy, multiple accounts, and avoiding spam—depend on how stable the SMS delivery actually is.

With **SMS-MAN performance test**, the goal is to measure how fast and reliable the service is under normal and high usage.

---

## 2. What is SMS-MAN performance test

**SMS-MAN performance test** is an evaluation of how the platform handles SMS delivery across different scenarios.

It measures:

- Latency (how fast SMS arrives)  
- Success rate (how often SMS is delivered)  
- Uptime (service availability)  

Instead of just describing features, **SMS-MAN performance test** looks at real behavior when receiving SMS online.

---

## 3. How SMS-MAN performance test works

**SMS-MAN performance test** is performed using repeated activations across services:

1. Request virtual numbers  
2. Trigger SMS from target platforms  
3. Measure delivery time  
4. Track failed attempts  
5. Monitor system availability  

Typical workflow remains the same as standard usage, but results are logged and analyzed.
